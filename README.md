
## 🔧 Настройка (для разработчиков)

В файле `index.html` в самом начале JavaScript-кода вы можете изменить основные параметры:

- `CELL_SIZE` — размер одной клетки (по умолчанию 32px в «крупной» версии, в обычной 20px)
- `COLS` и `ROWS` — размеры игрового поля в клетках
- `GAME_SPEED` — скорость движения змейки (мс на шаг)
- Массив `FOOD_TYPES` — характеристики каждого типа еды: бонус длины, очки, редкость (`weight`), цвет, время жизни (`lifetime`)

## 🧠 Как это работает

- Игровое поле — это `canvas`, обновляющийся по таймеру.
- Змейка представлена массивом сегментов, голова добавляется в начало, хвост удаляется.
- При поедании еды хвост не удаляется нужное число шагов (в зависимости от бонуса длины), что визуально увеличивает змейку.
- Еда генерируется по весовой вероятности, при исчезновении кристалла автоматически появляется новая еда.
- Столкновения со стенами и своим телом завершают игру с анимацией и затемнённым оверлеем.
